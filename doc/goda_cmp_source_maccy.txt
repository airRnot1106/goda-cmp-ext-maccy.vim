INTRODUCTION                             *goda-cmp-source-maccy-introduction*

                                                      *goda-cmp-source-maccy*
A goda-cmp.vim source for the recent clips of Maccy, the macOS clipboard
manager.  The source is named "maccy".

==============================================================================
INSTALL                                       *goda-cmp-source-maccy-install*

It needs goda-cmp.vim, goda.vim, Maccy and Neovim.

https://github.com/Shougo/goda-cmp.vim
https://github.com/Shougo/goda.vim
https://github.com/p0deje/Maccy

Add the Go package to your configuration module: >

	go get github.com/airRnot1106/goda-cmp-source-maccy
<
==============================================================================
EXAMPLES                                     *goda-cmp-source-maccy-examples*
>go
	import "github.com/airRnot1106/goda-cmp-source-maccy/ext/source/maccy"

	b.AddSource(maccy.New(maccy.Params{
		RecentMs: 300000,
		Types:    []string{"public.utf8-plain-text"},
		DBPath:   "~/Library/Containers/org.p0deje.Maccy/Data/Library/Application Support/Maccy/Storage.sqlite",
	}))
<
Add "maccy" to `Sources` and call |goda_cmp#build()|.

==============================================================================
PARAMS                                         *goda-cmp-source-maccy-params*

The parameters are also accepted in sourceParams with these JSON names.

recentMs		How old a clip may be, in milliseconds.
cacheTtlMs		How long the result of a query is reused.  0 or less
			disables the cache.
types			The pasteboard types to read.
dbPath			Maccy's Storage.sqlite.  A leading "~" is the home
			directory.
maxByteLength		Drops longer clips.
dedupe			Keeps only the newest clip of each value.
trimTrailingNewline	Removes trailing newlines before dedupe compares.
excludeAfterUse		Hides a clip accepted maxUseCount times.  Copying it
			again makes it new.
maxUseCount		See excludeAfterUse.
